# Diplom_1

# Дипломный проект: Автоматизация тестирования Stellar Burgers Задание 1

## Описание проекта

Проект представляет собой упрощённую модель приложения для заказа бургеров в Stellar Burgers.  
Основные классы проекта:

- `Bun` — модель булочки для бургера (название, цена).
- `Ingredient` — модель ингредиента (тип: соус или начинка, название, цена).
- `IngredientType` — enum с типами ингредиентов (`SAUCE`, `FILLING`).
- `Burger` — класс, который собирает бургер из булки и ингредиентов, поддерживает:
    - добавление, удаление и перемещение ингредиентов;
    - расчёт полной цены;
    - формирование чека (`getReceipt()`).
- `Database` — имитация базы данных, предоставляет списки доступных булок и ингредиентов.
- `Praktikum` — демонстрационный класс с методом `main()` для примера сборки бургера.

## Цель проекта

- Освоить автоматизацию тестирования на Java с использованием JUnit 4 и Mockito.
- Реализовать 100% покрытие юнит-тестами бизнес-логики приложения.
- Ознакомиться с инструментом анализа покрытия кода JaCoCo.

## Подключённые библиотеки

- **JUnit 4** — написание и запуск юнит-тестов.
- **Mockito** — создание мок-объектов для тестирования классов `Burger`, `Bun` и `Ingredient`.
- **JaCoCo** — анализ покрытия тестами.

## Покрытие тестами

- Класс `Burger` полностью покрыт тестами (`getPrice()`, `getReceipt()`, работа с ингредиентами).

- После запуска тестов и генерации отчёта JaCoCo все рабочие классы бизнес-логики имеют 100% покрытие.
